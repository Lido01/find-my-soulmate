# 🎮 Find My Soulmate — Developer Dating Simulation Web Game

A high-end developer-themed virtual dating simulation blending modern IDE aesthetics (VS Code, Dark Slate, Neon Glows) with a messaging client and dating dashboard.

## 🌟 Key Features

1. **Girlfriend 👩‍💻 & Boyfriend 👨‍💻 Selection Matrix**:
   - **Lina** (Finland): Hardcore Kernel Maintainer, tabs-only purist, git rebase romantic.
   - **Dani** (Global): Chaotic Frontend Ninja, Svelte & CSS grid enthusiast.
   - **Senait** (Ethiopia 🇪🇹): AI & Cloud Architect, PyTorch researcher, Ethiopian Bunna date host.
   - **Linus** (Finland): The OG blunt Kernel Maintainer.
   - **Devon** (Global): High-energy Frontend Architect, CSS animation wizard.
   - **Dawit** (Ethiopia 🇪🇹): Distributed Systems & Rust Guru, Ethio-Jazz lover.

2. **"Tell Me About Yourself" Onboarding & Profile Customizer**:
   - Customize your developer avatar emoji (🧑‍💻, 👩‍💻, 🤖, 🧙‍♂️, 🦊, ☕, ⚡, 🥷, 🦀).
   - Set dev archetype, favorite tech stack, relationship goal, and partner gender preference.

3. **Romantic Web Audio & Speech Voice Narration**:
   - Web Audio chords, heart pulses, and terminal chimes.
   - Interactive SpeechSynthesis (TTS) voice narration button on partner messages with animated audio sound waves.

4. **"How Much Love" Metrics & Romantic Drawer**:
   - Live Heartbeat BPM indicator (68–128 BPM).
   - Zero dropped packets & compatibility scores.
   - Quick developer love emojis & romantic quote cards in English & Amharic.

5. **Gemini AI Mode & Freeform Chat**:
   - Connect your Gemini API key in `AI Mode` for real-time unscripted AI roleplay with character system prompts.
   - Smart offline/scripted fallback with branching choices.

6. **Bilingual Support (English & Amharic አማርኛ)**:
   - Full UI and quote translations celebrating international and Ethiopian tech culture.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Open in browser
http://localhost:5173/
```
